# BRITON — نسخة معاينة أولية

هذه ملفات بداية لمتجر عربي RTL بلون أزرق داكن وأصفر، مع سلة مشتريات، فئات تجريبية، شريط تثبيت PWA، وتجهيز طلب واتساب.

## قبل النشر
1. استبدل `WHATSAPP_NUMBER` داخل `app.js` برقم واتساب التجاري مع رمز الدولة دون `+` أو مسافات.
2. استبدل المنتجات التجريبية والأسعار والصور داخل `app.js` و`index.html` ببيانات منتجاتك الفعلية.
3. اختبر الطلبات على الهاتف، ثم انشر الموقع على استضافة HTTPS.
4. لوحة الإدارة، الدفع الإلكتروني، المخزون الحقيقي، حسابات العملاء، وحفظ الطلبات في قاعدة بيانات ليست مفعّلة في هذه النسخة.
5. هذا المشروع ليس منشورًا على الإنترنت تلقائيًا، وملفاته لا تعطي رابط متجر عام حتى يتم رفعها إلى الاستضافة.

## معاينة محلية
افتح `index.html` لمشاهدة الواجهة. خصائص التثبيت والعمل دون اتصال تحتاج الاستضافة عبر HTTPS أو بيئة localhost.
